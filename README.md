# CodeMode

CodeMode is a Minecraft plugin designed for server version 1.20.1 that allows server administrators to modify and add features through coding, similar to Denizen and Skript. This plugin provides a framework for creating custom features, enabling server owners to extend the functionality of their Minecraft server with ease.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` directory of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. **Add a Custom Feature**:
   - Use the command `/customfeature add <featureName>` to add a new custom feature.
   - Replace `<featureName>` with the name of the feature you want to add.

2. **Remove a Custom Feature**:
   - Use the command `/customfeature remove <featureName>` to remove an existing custom feature.
   - Replace `<featureName>` with the name of the feature you want to remove.

3. **List Custom Features**:
   - Use the command `/customfeature list` to list all currently loaded custom features.
